# Linux Learning Journey 🐧

A repository documenting my Linux and Shell Scripting learning journey as I prepare for Cloud and DevOps roles.

Instead of simply collecting commands, this repository focuses on understanding Linux concepts, practicing them through hands-on exercises, and building real-world shell scripting projects.

---

## 📌 Objectives

* Learn Linux fundamentals from the command line.
* Practice Linux commands consistently.
* Write reusable Bash/Shell scripts.
* Build practical Linux mini projects.
* Document progress in a structured and organized manner.
