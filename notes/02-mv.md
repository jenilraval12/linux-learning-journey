# Notes 02 — `mv` Command

## 📖 Introduction

The `mv` (**Move**) command is used to **move** or **rename** files and directories in Linux. It is one of the most frequently used file management commands and is essential for organizing files and folders.

Unlike `cp`, which creates a copy, `mv` transfers the original file to a new location or changes its name.

---

# Syntax

```bash
mv [OPTIONS] SOURCE DESTINATION
```

---

# Basic Usage

## 1. Rename a File

Rename an existing file.

### Command

```bash
mv notes.txt linux-notes.txt
```

### Before

```
notes.txt
```

### After

```
linux-notes.txt
```

---

## 2. Rename a Directory

Directories can also be renamed.

### Command

```bash
mv Projects DevOps-Projects
```

### Before

```
Projects/
```

### After

```
DevOps-Projects/
```

---

## 3. Move a File to Another Directory

Move a file without changing its name.

### Command

```bash
mv report.pdf Documents/
```

### Before

```
.
├── report.pdf
└── Documents/
```

### After

```
.
└── Documents/
    └── report.pdf
```

---

## 4. Move Multiple Files

Move several files into a directory.

### Command

```bash
mv file1.txt file2.txt file3.txt Backup/
```

---

## 5. Move an Entire Directory

```bash
mv Linux Notes/
```

Output

```
Notes/
└── Linux/
```

---

# Common Options

## 6. Interactive Mode (`-i`)

Ask before overwriting an existing file.

### Command

```bash
mv -i notes.txt Documents/
```

Output

```
mv: overwrite 'Documents/notes.txt'?
```

---

## 7. Force Move (`-f`)

Overwrite files without asking for confirmation.

```bash
mv -f notes.txt Documents/
```

> Use with caution because existing files may be overwritten.

---

## 8. Do Not Overwrite (`-n`)

Never overwrite an existing file.

```bash
mv -n notes.txt Documents/
```

If the destination file exists, nothing happens.

---

## 9. Verbose Mode (`-v`)

Display each operation performed.

```bash
mv -v notes.txt Documents/
```

Output

```
renamed 'notes.txt' -> 'Documents/notes.txt'
```

---

## 10. Update Only If Source is Newer (`-u`)

Move only if the source file is newer than the destination.

```bash
mv -u report.txt Backup/
```

Useful for updating backups.

---

## 11. Backup Existing Files (`-b`)

Create a backup before overwriting.

```bash
mv -b notes.txt Documents/
```

Output

```
notes.txt~
```

The old file is saved with a `~` suffix.

---

# Combining Options

```bash
mv -iv notes.txt Documents/
```

This command:

- `-i` → Ask before overwrite
- `-v` → Show what happened

# Advanced Examples

## Example 1: Organize Downloads

```bash
mv *.pdf Documents/
```

Moves all PDF files into the `Documents` directory.

---

## Example 2: Move All Images

```bash
mv *.jpg Pictures/
```

Moves every JPG image into `Pictures`.

---

## Example 3: Move Log Files

```bash
mv *.log Logs/
```

Moves all log files into the `Logs` directory.

---

## Example 4: Rename Multiple Files Using a Loop

```bash
for file in *.txt
do
    mv "$file" "${file%.txt}.md"
done
```

Converts:

```
Day1.txt
Day2.txt
Day3.txt
```

into

```
Day1.md
Day2.md
Day3.md
```

---

## Example 5: Move Hidden Files

```bash
mv .env Config/
```

Moves the hidden `.env` file.

# Common Errors

## Error: No Such File

```bash
mv abc.txt docs/
```

Output

```
mv: cannot stat 'abc.txt': No such file or directory
```

### Solution

Check the filename:

```bash
ls
```

---

## Error: Destination Directory Does Not Exist

```bash
mv report.pdf Backup/
```

Output

```
mv: cannot move 'report.pdf' to 'Backup/': No such file or directory
```

### Solution

```bash
mkdir Backup
mv report.pdf Backup/
```

---

## Error: Permission Denied

```bash
mv file.txt /root/
```

Output

```
mv: cannot move 'file.txt': Permission denied
```

### Solution

```bash
sudo mv file.txt /root/
```

# Exit Status

| Exit Code | Meaning |
|-----------|---------|
| `0` | Successful |
| Non-zero | Error occurred |

Example

```bash
mv file.txt Documents/
echo $?
```

Output

```
0
```

# Difference Between `mv` and `cp`

| Feature | `mv` | `cp` |
|---------|------|------|
| Moves file | ✅ | ❌ |
| Copies file | ❌ | ✅ |
| Renames files | ✅ | ❌ |
| Original remains | ❌ | ✅ |

---

# Common Flags

| Flag | Description |
|------|-------------|
| `-i` | Ask before overwrite |
| `-f` | Force overwrite |
| `-n` | Never overwrite |
| `-v` | Verbose output |
| `-u` | Move only newer files |
| `-b` | Backup overwritten files |
| `--help` | Display help |
| `--version` | Show version |

---

# Best Practices

- Use `-i` to avoid accidental overwrites.
- Use `-v` while learning to understand what happens.
- Verify destination directories before moving files.
- Use `-b` when working with important files.
- Prefer descriptive filenames before renaming.

# Key Takeaways

- `mv` stands for **Move**.
- It is used to **move** and **rename** files and directories.
- Unlike `cp`, `mv` does **not** leave the original file behind.
- Use `-i` for safety, `-v` for learning, and `-n` to prevent overwriting.
- Wildcards (`*`) make moving multiple files quick and efficient.
