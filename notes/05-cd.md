# Notes 05 — `cd` Command

## 📖 Introduction

The `cd` (**Change Directory**) command is used to navigate between directories in Linux. Unlike `pwd`, which only displays your current location, `cd` changes your current working directory.

It is one of the most frequently used Linux commands because almost every task begins with navigating to the correct directory.

---

# Syntax

```bash
cd [DIRECTORY]
```

If no directory is specified, `cd` takes you to your home directory.

---

# Basic Usage

## 1. Change to a Directory

Moves from the current directory to the specified directory.

### Command

```bash
cd Documents
```

### Example

Current directory:

```text
/home/jenil
```

Command:

```bash
cd Documents
```

Now your current directory becomes:

```text
/home/jenil/Documents
```

---

# Understanding Directory Navigation

Suppose your current directory is:

```text
/home/jenil/Documents/Linux
```

It can be broken down as follows:

| Part | Meaning |
|------|---------|
| `/` | Root directory |
| `home` | Home directory containing user accounts |
| `jenil` | Username |
| `Documents` | Parent directory |
| `Linux` | Current working directory |

Using `cd` changes your current location within this directory structure.

---

# Absolute Path vs Relative Path

## Absolute Path

An absolute path starts from the root directory (`/`).

Example:

```bash
cd /home/jenil/Documents/Linux
```

No matter where you currently are, this command always takes you to the same location.

---

## Relative Path

A relative path starts from your current directory.

Suppose your current directory is:

```text
/home/jenil
```

Then:

```bash
cd Documents
```

moves you to:

```text
/home/jenil/Documents
```

---

# Common Navigation Commands

## 2. Go to the Home Directory

### Command

```bash
cd
```

or

```bash
cd ~
```

Output:

```text
/home/jenil
```

---

## 3. Go to the Parent Directory

Moves one level up.

### Command

```bash
cd ..
```

Example:

Before:

```text
/home/jenil/Documents/Linux
```

After:

```text
/home/jenil/Documents
```

---

## 4. Go to the Root Directory

### Command

```bash
cd /
```

Output:

```text
/
```

---

## 5. Return to the Previous Directory

Switches back to the last working directory.

### Command

```bash
cd -
```

Example

Current directory:

```text
/home/jenil/Documents
```

Previous directory:

```text
/home/jenil/Downloads
```

Running:

```bash
cd -
```

Output:

```text
/home/jenil/Downloads
```

---

# Helpful Commands

## Show Help

```bash
cd --help
```

> **Note:** `cd` is a shell built-in command in Bash, so help is usually accessed using:

```bash
help cd
```

---

# Common Shortcuts

| Shortcut | Description |
|----------|-------------|
| `cd` | Go to the home directory |
| `cd ~` | Go to the home directory |
| `cd ..` | Go to the parent directory |
| `cd -` | Return to the previous directory |
| `cd /` | Go to the root directory |
| `cd .` | Stay in the current directory |

# Common Errors

## Directory Does Not Exist

```bash
cd Downloads123
```

Output:

```text
bash: cd: Downloads123: No such file or directory
```

---

## Permission Denied

Trying to enter a directory without execute permission.

Example:

```bash
cd secure-folder
```

Output:

```text
bash: cd: secure-folder: Permission denied
```

---

# Exit Status

| Exit Code | Meaning |
|-----------|---------|
| `0` | Command executed successfully |
| Non-zero | An error occurred |

Example

```bash
cd Documents
echo $?
```

Output

```text
0
```

---

# Difference Between `cd` and `pwd`

| Command | Purpose |
|---------|---------|
| `cd` | Change the current directory |
| `pwd` | Display the current directory |

Example:

```bash
pwd
```

Output

```text
/var
```

Now change directory:

```bash
cd /home/jenil
pwd
```

Output

```text
/home/jenil
```

---

# Best Practices

- Use relative paths whenever possible.
- Use absolute paths when scripting to avoid ambiguity.
- Verify your current location with `pwd`.
- Use **Tab** for auto-completion instead of typing full directory names.
- Learn shortcuts like `cd ..` and `cd -` to navigate efficiently.

# Key Takeaways

- `cd` stands for **Change Directory**.
- It changes your current working directory.
- It supports both **absolute** and **relative** paths.
- `cd ..` moves up one directory.
- `cd -` returns to the previous directory.
- `cd` or `cd ~` returns to your home directory.
- `pwd` is commonly used alongside `cd` to verify your current location.
