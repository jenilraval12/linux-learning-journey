# `cd` Command

The `cd` (Change Directory) command is used to navigate between directories in Linux. It is one of the most frequently used commands when working in the terminal.

---

## Syntax

```bash
cd [directory]
```

If no directory is specified, `cd` takes you to your home directory.

---

## Basic Examples

### 1. Change to a specific directory

```bash
cd Documents
```

Moves into the `Documents` directory.

---

### 2. Move to the parent directory

```bash
cd ..
```

Example:

Before:

```text
/home/jenil/Documents
```

After:

```text
/home/jenil
```

---

### 3. Move to the previous directory

```bash
cd -
```

Example:

Current directory:

```text
/home/jenil/Documents
```

Run:

```bash
cd -
```

Output:

```text
/home/jenil/Downloads
```

This command switches between the current and previously visited directory.

---

### 4. Move to the home directory

```bash
cd
```

or

```bash
cd ~
```

Output:

```text
/home/jenil
```

---

### 5. Move to the root directory

```bash
cd /
```

Output:

```text
/
```

---

### 6. Navigate using an absolute path

```bash
cd /home/jenil/Documents/Linux
```

Moves directly to the specified location.

---

### 7. Navigate using a relative path

Suppose you are currently in:

```text
/home/jenil
```

Run:

```bash
cd Documents
```

You will move to:

```text
/home/jenil/Documents
```

---

## Special Symbols

| Symbol | Meaning |
|---------|---------|
| `.` | Current directory |
| `..` | Parent directory |
| `~` | Home directory |
| `/` | Root directory |
| `-` | Previous directory |

## Tips

- Directory names are **case-sensitive**.
- Press **Tab** to auto-complete directory names.
- Use `pwd` if you're unsure of your current location.
- Use `ls` to view the contents of the current directory before changing into another directory.

## Related Commands

- `pwd` — Print the current working directory.
- `ls` — List files and directories.
- `mkdir` — Create a new directory.
- `rmdir` — Remove an empty directory.
