# Notes 03 — `rm` Command

## 📖 Introduction

The `rm` (**Remove**) command is used to delete files and directories in Linux. It is one of the most powerful commands because **deleted files generally cannot be recovered** through normal means.

> ⚠️ **Warning:** Always double-check before running `rm`, especially as the root user. Once a file is removed, it usually cannot be restored.

---

# Syntax

```bash
rm [OPTIONS] FILE...
rm [OPTIONS] DIRECTORY...
```

---

# Basic Usage

## 1. Remove a Single File

Delete a single file.

### Command

```bash
rm notes.txt
```

### Before

```
notes.txt
```

### After

```
File deleted
```

---

## 2. Remove Multiple Files

Delete multiple files at once.

### Command

```bash
rm file1.txt file2.txt file3.txt
```

---

## 3. Remove All Files with the Same Extension

Delete all `.txt` files.

### Command

```bash
rm *.txt
```

### Example

Before

```
Day1.txt
Day2.txt
Notes.txt
```

After

```
(All deleted)
```

---

# Common Options

## 4. Interactive Mode (`-i`)

Ask for confirmation before deleting each file.

### Command

```bash
rm -i notes.txt
```

### Output

```
rm: remove regular file 'notes.txt'?
```

Type:

```
y
```

to delete.

---

## 5. Force Delete (`-f`)

Delete files without asking for confirmation.

### Command

```bash
rm -f notes.txt
```

Useful for scripts but should be used carefully.

---

## 6. Verbose Mode (`-v`)

Show every file being deleted.

### Command

```bash
rm -v notes.txt
```

### Output

```
removed 'notes.txt'
```

---

## 7. Remove Empty Directories

The `rm` command can remove empty directories using `-d`.

```bash
rm -d EmptyFolder
```

---

## 8. Remove Directories Recursively (`-r`)

Delete a directory and all of its contents.

### Command

```bash
rm -r Projects
```

Before

```
Projects/
├── README.md
├── src/
└── docs/
```

After

```
Projects removed completely
```

---

## 9. Force Remove Directories (`-rf`)

Delete directories recursively without confirmation.

### Command

```bash
rm -rf Projects
```

> ⚠️ This is one of the most dangerous Linux commands. Use it only when you're absolutely sure.

---

## 10. Recursive + Interactive

Ask before deleting files inside a directory.

```bash
rm -ri Projects
```

---

## 11. Recursive + Verbose

Display every file and folder removed.

```bash
rm -rv Projects
```

---

## 12. Force + Recursive + Verbose

```bash
rm -rfv Projects
```

This command:

- `-r` → Delete recursively
- `-f` → Force deletion
- `-v` → Show deleted files

# Common Errors

## Error: Is a Directory

```bash
rm Projects
```

Output

```
rm: cannot remove 'Projects': Is a directory
```

### Solution

```bash
rm -r Projects
```

---

## Error: Permission Denied

```bash
rm file.txt
```

Output

```
rm: cannot remove 'file.txt': Permission denied
```

### Solution

```bash
sudo rm file.txt
```

---

## Error: No Such File

```bash
rm abc.txt
```

Output

```
rm: cannot remove 'abc.txt': No such file or directory
```

### Solution

Verify the filename.

```bash
ls
```

| Exit Code | Meaning |
|-----------|---------|
| `0` | Successful |
| Non-zero | Error occurred |

Example

```bash
rm notes.txt

```

Output

```
0
```

# Difference Between `rm` and `rmdir`

| Feature | `rm` | `rmdir` |
|---------|------|---------|
| Remove files | ✅ | ❌ |
| Remove empty directories | ✅ (`-d`) | ✅ |
| Remove non-empty directories | ✅ (`-r`) | ❌ |
| Recursive deletion | ✅ | ❌ |

---

# Common Flags

| Flag | Description |
|------|-------------|
| `-i` | Ask before deleting |
| `-f` | Force deletion |
| `-r` / `-R` | Delete recursively |
| `-d` | Remove empty directory |
| `-v` | Verbose output |
| `--help` | Display help |
| `--version` | Show version |

---

# Best Practices

- Always verify the file before deleting.
- Use `-i` if you're unsure.
- Use `-v` while learning.
- Avoid using `rm -rf` unless necessary.
- Never run commands like:

```bash
rm -rf /
```

or

```bash
sudo rm -rf /
```

These commands can destroy the entire Linux system.

# Cheat Sheet

| Command | Description |
|---------|-------------|
| `rm file.txt` | Delete a file |
| `rm file1 file2` | Delete multiple files |
| `rm *.txt` | Delete all `.txt` files |
| `rm -i file` | Ask before deleting |
| `rm -f file` | Force delete |
| `rm -v file` | Show deleted file |
| `rm -d folder` | Delete empty directory |
| `rm -r folder` | Delete directory recursively |
| `rm -rf folder` | Force delete directory |
| `rm -rv folder` | Recursive + verbose |
| `rm -rfv folder` | Recursive + force + verbose |
| `rm --help` | Show help |
| `rm --version` | Show version |

---

# Key Takeaways

- `rm` stands for **Remove**.
- It is used to delete files and directories.
- `-r` deletes directories recursively.
- `-f` skips confirmation prompts.
- `-i` is safer because it asks before deleting.
- `-v` displays every deletion.
- `rm -rf` is extremely powerful and should be used with caution.
- Deleted files are usually **not recoverable**, so always verify before deleting.
